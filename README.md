# まるみっつー（非公式）

ランドとシーのあちこちにかくれている「丸が3つ」のマークを探して、写真でスタンプを集める非公式ファンアプリです。

- 地図の番号をタップするとヒントが読めます。見つけたら写真を撮ると、スタンプが押されます。
- 近くに来るとお知らせが届きます（アプリを開いているあいだだけ）。
- ホーム画面に追加すると、アプリのように使えます（オフラインでも開けます）。

## 注意
- 個人のファンが作った非公式アプリです。パークを運営する会社やキャラクターの権利を持つ会社とは関係ありません。
- 名前・アイコン・地図には、キャラクターや公式の素材を使っていません。地図は © OpenStreetMap contributors。
- ヒントと答えは、いろいろな情報をもとに自分の言葉で書いたものです（出典は各答えの最後）。改装などでなくなっていることがあります。
- 撮った写真と記録は、使っている端末の中だけに保存されます。

## ファイル
- `index.html` … 画面の部品
- `style.css` … 見た目
- `marks.js` … マークのデータ（番号・場所・ヒント・答え）
- `app.js` … 動き（地図、スタンプ、カメラ、GPS）
- `sw.js` … オフライン対応
