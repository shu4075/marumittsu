## 段階0：仕上げ（今のWebアプリのまま）

ストアの審査で必ず聞かれるもの・使う人が困らないためのもの。

1. **プライバシーポリシーのページ**（ストアに出すには必須）
   - 集める情報：位置情報（アプリの中だけで使い、どこにも送らない）、カメラの写真（スマホの中だけに保存）
   - 広告やアクセス解析は入れていない、と書く
2. **利用規約・非公式の注意のページ**
   - 非公式であること、運営会社・権利を持つ会社と関係ないこと
   - パークのルール（撮影マナー、立入禁止の場所に入らない、歩きスマホをしない）を守ってもらう
3. **問い合わせ先**（ストアに必須）：問い合わせ用のメールか、Googleフォーム
4. **言葉の見直し**
   - 答えの文章に残っている「ミッキー」を「マーク」などに言いかえる（名前・アイコンにはもう使っていない）
   - 出典のサイト名はそのまま残す
5. **中身の確認**（あなたにお願い）
   - パークで実際に見つけて、「未確認」→「確認済み」にする。答えの写真を入れる
   - なくなっていたマークは消す
6. **初めて開いたときの説明**（3枚くらいのかんたんな説明）
7. **記録を消すボタン**（スタンプと写真を全部消す）
8. **見た目と使いやすさの点検**（文字の大きさ、色の見やすさ、ボタンの押しやすさ）

## 段階1：Android（Google Play）

### 作り方
- **Capacitor（キャパシター）** という道具で、今のWebアプリをそのままAndroidアプリの形に包む。
  - 今のHTML・CSS・JavaScriptがほぼそのまま使える
  - Windowsでも作れる（Android Studio を入れる）
- アプリにすると、Webではできなかったことができる：
  - **アプリを閉じていても、近くに来たらお知らせ**（バックグラウンドの位置情報＋通知）
  - スマホ本来のカメラ画面を使う

### 公開までの手順
1. Google Play デベロッパーアカウントを作る（25ドル・本人確認あり）
2. アプリを組み立てて、Play Console に上げる
3. **クローズドテスト：12人以上のテスターに、14日間続けて入ってもらう**
   - 2023年11月以降に作った個人アカウントは、これをしないと一般公開できない
   - 途中で人が抜けると数え直しになるので、15〜20人くらい集めると安心
   - 友だちに「テストに参加」ボタンを押してもらい、ときどき開いてもらう
4. 一般公開を申請 → 審査（数日〜1週間くらい）

### 気をつけること
- バックグラウンドの位置情報を使うときは、「なぜ必要か」の説明と動画を出す必要がある
- ストアのページに、非公式であることをはっきり書く

## 段階2：iPhone（App Store）

### 作り方
- 段階1と同じ Capacitor のものを、iPhone用に組み立てる
- iPhone用の組み立てには本来Macが必要。**Codemagic** というネット上の組み立てサービスを使えば、Windowsだけでできる（個人は毎月500分まで無料。1回の組み立ては5〜8分くらい）

### 公開までの手順
1. Apple Developer Program に登録（年99ドル）
2. Codemagic で組み立てて、TestFlight（テスト配信）で自分のiPhoneに入れて確かめる
3. 審査に出す

### 審査で心配なところ
- **他社の権利（5.2.1）**：パークに関係するアプリなので、許可を示す書類を求められることがある。非公式であること、名前・アイコンに公式の素材を使っていないことを、審査メモに説明する
- **中身が少ない（4.2）**：Webサイトを包んだだけに見えると断られやすい。スタンプ帳、カメラ、閉じていても届くお知らせなど、アプリならではの機能があることを示す
- 断られても、直して出し直せる
